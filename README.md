# ✦ COSMIC CLICKER

宇宙をテーマにした放置系クリッカーです。バニラ HTML / CSS / JavaScript のみで動作し、ビルド不要です。

コアをクリックしてスターダストを集め、施設を購入して自動生産を強化、アップグレードで生産効率を上げ、十分に稼いだら「転生」して特異点コアを獲得し永続的な倍率を得られます。

## 特徴

- **クリック**: コアをクリックしてスターダストを獲得（10%の確率でクリティカル、通常の5倍）
- **施設タブ**: 自動生産する施設を購入（所持数に応じてコストが上昇）
- **アップグレードタブ**: 稼いだ総量に応じて解放される強化を購入
- **実績タブ**: クリック数・累計獲得量・施設所持・転生回数などの条件を達成すると解除され、それぞれ生産量への永続ボーナスを獲得
- **黄金のスターダスト**: 数十秒に一度ランダムに出現するボーナスオーブ。クリックすると「即時ボーナス」「クリック威力7倍（フレンジー）」「生産量3倍（サージ）」のいずれかを獲得
- **転生**: 一定量を稼ぐと解放。リセットする代わりに永続倍率を獲得
- **バックグラウンド対応**: タブを非表示にしていても実時間ベースで生産が進み、戻ってきた瞬間に反映される
- **オフライン進行**: ページを閉じて再訪した際も、離れていた時間分の生産を自動計算
- 進行状況はブラウザの `localStorage` に自動保存（同じサイト内であれば引き継がれます）

## 遊び方

`index.html` を直接ブラウザで開くか、ローカルサーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

GitHub Pages が有効な場合は `main` ブランチへの push で自動デプロイされます（`.github/workflows/pages.yml`）。

## ファイル構成

- `index.html` — 画面構成（HUD・施設/アップグレードタブ・転生モーダル）
- `style.css` — 宇宙モチーフのビジュアルスタイル
- `script.js` — ゲームロジック（生産計算、購入処理、転生、セーブ/ロード）
