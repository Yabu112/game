# GAME

ブラウザで遊べるミニゲーム集です。バニラ HTML / CSS / JavaScript のみで動作し、ビルド不要です。

## 収録タイトル

### 🌌 NEON SURVIVOR（ルート直下）

ローグライト・サバイバルシューティング。時間経過とともに敵の数・強さが増していくウェーブ制で、敵を倒すと経験値を獲得。レベルアップ時に3択のランダムアップグレードから強化を選ぶため、プレイごとに展開が変わり周回しても飽きにくい設計です。

- **移動**: `W` `A` `S` `D` または矢印キー（タッチ操作にも対応）
- **攻撃**: 自動で最も近い敵を攻撃
- **一時停止**: `Esc`
- ベストスコアはブラウザの `localStorage` に保存

ファイル: `index.html` / `style.css` / `game.js`

### ✦ COSMIC CLICKER（`clicker/`）

宇宙をテーマにした放置系クリッカー。コアをクリックしてスターダストを集め、施設を購入して自動生産を強化、アップグレードで生産効率を上げ、十分に稼いだら「転生」して特異点コアを獲得し永続的な倍率を得られます。放置していても遊びに戻ってきた際にオフライン分の生産を自動計算する仕組みも搭載。

- **クリック**: コアをクリックしてスターダストを獲得
- **施設タブ**: 自動生産する施設を購入（所持数に応じてコストが上昇）
- **アップグレードタブ**: 稼いだ総量に応じて解放される強化を購入
- **転生**: 一定量を稼ぐと解放。リセットする代わりに永続倍率を獲得
- 進行状況はブラウザの `localStorage` に自動保存

ファイル: `clicker/index.html` / `clicker/style.css` / `clicker/script.js`

## 遊び方

各ゲームのディレクトリで `index.html` を直接ブラウザで開くか、リポジトリのルートでローカルサーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/            → NEON SURVIVOR
# http://localhost:8000/clicker/    → COSMIC CLICKER
```
