# 🌸 GARDEN CLICKER

庭園をテーマにした、明るく爽やかな放置系クリッカーです。バニラ HTML / CSS / JavaScript のみで動作し、ビルド不要です。

花をクリックして花びらを集め、庭園設備を購入して自動収穫を強化、アップグレードで効率を上げ、十分に稼いだら「季節を巡らせて」黄金の種を獲得し永続的な倍率を得られます。

## 特徴

- **クリック**: 花をクリックして花びらを獲得（10%の確率でクリティカル、通常の5倍）。`スペースキー`でもクリックできる
- **花びらの演出**: クリックのたびに花びらが1枚舞い散り、少し経つとまた生えてくる
- **効果音**: クリック・購入・実績解除・季節を巡らせる操作などに軽い効果音（右上のアイコンでミュート可）
- **庭園タブ**: 自動収穫する設備を購入（所持数に応じてコストが上昇）。×1/×10/×100/MAXでまとめ買いが可能
- **アップグレードタブ**: 稼いだ総量に応じて解放される強化を購入
- **実績タブ**: クリック数・累計獲得量・設備所持・季節を巡らせた回数などの条件を達成すると解除され、それぞれ生産量への永続ボーナスを獲得
- **黄金の花びら**: 数十秒に一度ランダムに出現するボーナスオーブ。クリックすると「即時ボーナス」「収穫力7倍（満開フィーバー）」「生産量3倍（めぐみの雨）」のいずれかを獲得
- **季節を巡らせる**: 一定量を稼ぐと解放。リセットする代わりに永続倍率（黄金の種）を獲得
- **バックグラウンド対応**: タブを非表示にしていても実時間ベースで生産が進み、戻ってきた瞬間に反映される
- **オフライン進行**: ページを閉じて再訪した際も、離れていた時間分の生産を自動計算
- 進行状況はブラウザの `localStorage` に自動保存（同じサイト内であれば引き継がれます）

## 遊び方

`index.html` を直接ブラウザで開くか、ローカルサーバーを立てて開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/
```

GitHub Pages が有効な場合は `main` ブランチへの push で自動デプロイされます（`.github/workflows/pages.yml`）。

## ファイル構成

- `index.html` — 画面構成（HUD・庭園/アップグレード/実績タブ・季節を巡らせるモーダル）
- `style.css` — 明るい庭園モチーフのビジュアルスタイル
- `script.js` — ゲームロジック（生産計算、購入処理、季節を巡らせる処理、セーブ/ロード）
