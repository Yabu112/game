# NEON SURVIVOR

ブラウザで遊べるローグライト・サバイバルシューティングです。バニラ HTML / CSS / JavaScript のみで動作し、ビルド不要です。

## 遊び方

`index.html` をブラウザで開くか、ローカルサーバーを立てて `http://localhost:8000` などにアクセスしてください。

```bash
python3 -m http.server 8000
```

- **移動**: `W` `A` `S` `D` または矢印キー（タッチ操作にも対応）
- **攻撃**: 自動で最も近い敵を攻撃
- **一時停止**: `Esc`

## 特徴

- 時間経過とともに敵の数・強さが増していくウェーブ制サバイバル
- 敵を倒すと経験値を獲得し、レベルアップ時に3択のランダムアップグレードから強化を選択
- 4種類の敵（通常・高速・重量級・遠距離）が異なる脅威を生む
- プレイごとにアップグレードの組み合わせが変わるため、周回して遊んでも飽きにくい設計
- ベストスコアはブラウザの `localStorage` に保存

## ファイル構成

- `index.html` — 画面構成（HUD・スタート/レベルアップ/ゲームオーバー画面）
- `style.css` — ネオン風のビジュアルスタイル
- `game.js` — ゲームロジック（敵スポーン、戦闘、アップグレード、描画ループ）
